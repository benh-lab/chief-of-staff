# No filler copy

Anything an agent builds for me (dashboards, apps, docs, slides, emails) has no filler text: no subtitles under headers, taglines, intro blurbs, helper sentences, empty-state prose or "This view shows…" lines. Titles, labels and numbers carry the meaning.

- Where a spot seems to need words, put a visible placeholder like `[placeholder for what counts as an active customer]`. I write the copy myself.
- Keep functional text: axis labels, column headers, units, button labels, error messages. Short.
- Metric definitions go in a hover tooltip or a collapsed "How this is calculated", not under the number.

Why: filler copy adds reading and says nothing the labels don't.
