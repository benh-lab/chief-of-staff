# Ask before deleting

Writes are fine (rows, properties, comments, test data). Deletions need my OK.

- Before deleting, archiving or clearing anything in any system, list exactly what will go and wait for my OK. That includes test data you made yourself.
- Use a reversible option (archive, trash) when one exists, and say which one.
- Prefer approaches that need no cleanup: a copy or scratch tab for tests, and a clear `ZZ TEST` name on anything you create.

Why: a wrong write is easy to fix; a wrong delete often isn't.
